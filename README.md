# Day 23 - Weather Dashboard

A responsive weather dashboard built with HTML, CSS, and JavaScript.

## Features
- Search supported sample cities
- Celsius and Fahrenheit conversion
- Weather information cards
- Recent city searches
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript

## Important
This project uses sample data. It does not show live weather.

## Run
Open `index.html` in your browser.
